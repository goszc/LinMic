# LinMic

[Português (Brasil)](../../README.md) · [English](README.en.md) · [Español](README.es.md) · **Русский** · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

Используйте телефон Android как микрофон для Linux. Нативные приложения, без аккаунта и облака. **0.3.0 (Android) / 0.2.0 (Linux) · Android 8+ · Linux с PipeWire**, основная платформа — CachyOS/Arch.

## Установка и подключение

1. Скачайте [последний выпуск](https://github.com/goszc/LinMic/releases/latest).
2. Распакуйте архив Linux и выполните `./scripts/install-linux.sh` от обычного пользователя, без sudo. Откройте **LinMic** через меню приложений.
3. Установите APK на Android. Подключите устройства к одной частной сети или включите USB-модем.
4. На компьютере нажмите **Подключить телефон**. На Android выберите найденный ПК или введите его IP, разрешите доступ к микрофону и введите **шестизначный код**. Копировать отпечаток сертификата не нужно.
5. Выберите **LinMic** как вход в Discord, OBS или другом приложении.

Код действует две минуты, используется один раз и допускает до пяти попыток. Последующие соединения аутентифицируются автоматически. Перед установкой release APK необходимо один раз удалить отладочный APK 0.1.0: используется новая подпись. Следующие выпуски сохранят release-ключ.

## Звук и интерфейс

Opus, моно, 48 кГц; Ultra (5 мс), Balanced (10 мс), Stable (20 мс). Усиление до +24 дБ с плавными изменениями и лимитером -1 dBFS. Усиление на телефоне и компьютере независимо. Начните с 0 дБ: цифровое усиление также усиливает имеющийся шум.

Название входа сочетает тип и имя устройства Android; список обновляется при подключении аксессуаров. Android не всегда предоставляет отдельные капсюли микрофона. Bluetooth может заметно увеличить задержку. Показанная задержка — оценка, а не акустическое измерение.

Доступны выключение микрофона, переподключение, осциллограмма, индикаторы уровня, статистика, системный трей и глобальные сочетания клавиш через портал рабочего стола. Закрытие интерфейса не останавливает службу. Оба приложения поддерживают португальский, английский, испанский, русский, упрощённый китайский и японский. На Android язык выбирается в Настройки → Интерфейс; после выбора языка на ПК перезапустите интерфейс.

## Сборка

```sh
sudo pacman -S --needed rust cmake ninja clang pkgconf pipewire opus gtk4
cargo build --locked --release --workspace
cargo test --workspace
```

Для Android нужны JDK 17, SDK 36, NDK 28.2.13676358, CMake 3.22.1, Python и цели Rust `aarch64-linux-android`, `armv7-linux-androideabi`, `x86_64-linux-android`. В каталоге `android/` выполните `./gradlew assembleDebug testDebugUnitTest lintDebug`.

Локальная подпись: `python3 scripts/sign-android.py`. Сохраните закрытую резервную копию `~/.local/share/linmic-signing`; не публикуйте её. Порты локальной сети: TCP 39820, UDP 39821, mDNS UDP 5353.
